## 摘要

本文试图将当前两种彼此分离的语言研究与语言实践路径结合起来——一方是大语言模型，另一方是欧陆哲学，尤其是马丁·海德格尔的语言之思，以及在弗洛伊德基础上由雅克·拉康发展起来的结构精神分析。我们将表明，海德格尔、弗洛伊德和拉康在临床框架中所讨论和运用的语言概念，与现代大语言模型有着相当强的契合。这使得我们能够讨论一个在欧陆话语中处于核心位置、却在当前大语言模型研究中付诸阙如的问题——即否定性与否定本身的问题。这也意味着，我们提供的是一种与通常的人工智能哲学截然不同的进路，因为我们所依据的思想家在更贴近AI研究的分析哲学话语中往往被忽略。为此，我们也会指出这种进路在本体论层面上的差异所在。不过，我们的目标读者既包括AI研究者，也包括欧陆哲学家。

## 1. 引言

2023年，诺姆·乔姆斯基等人在《纽约时报》的一篇评论文章中，用一句颇为引人注目的话来评价当代大语言模型：“鉴于这些系统缺乏道德感、充斥着伪科学、且语言能力低下，我们对其流行只能报以苦笑或哭泣。”（Chomsky et al., 2023）这话听起来或许让人意外，尤其是因为彼时这些系统已经展现出了惊人的理解人类语言的能力，甚至能处理相当复杂的科学文本。在某种意义上，乔姆斯基说得没错：ChatGPT以及其他大语言模型确实存在（它们自己也承认的）困难。但问题在于，乔姆斯基究竟是指出了问题的要害，还是把问题给搅混了。乔姆斯基主张基于规则的系统，而另一些人，比如弗雷德里克·杰利内克，则走上了一条截然不同的路。在AI与语言学的关系上，杰利内克那句名言——“每当我解雇一个语言学家，语音识别系统的表现就会提升”——对于受过乔姆斯基理论训练的语言学家来说，尤其刺耳。杰利内克是统计语言处理领域的先驱，他推动了从基于规则的系统（比如植根于乔姆斯基理论的那一类）向数据驱动方法的转变。现代大语言模型，如GPT-4，虽然并非直接建立在杰利内克的工作之上，但其依赖于深度学习和神经网络来处理和生成类人文本的能力，无疑在很大程度上受益于杰利内克对数据驱动方法和统计路径的强调。这说明，乔姆斯基的批判深深植根于当代AI研究与语言学之间的关联方式。

那么，乔姆斯基等人对大语言模型的具体论点是什么呢？他们在评论文章中主张，真正的人类能力是以规则系统为基础进行运作的，而“浸泡在大数据中”（Chomsky et al., 2023）远远不够。但值得注意的是，就日常语言而言，浸泡在大数据里所达到的效果，在令人惊讶的程度上已经足够用了。乔姆斯基等人认为，要想像人一样思考，AI需要被“赋予”与人相同的“普遍语法”（2023）。有意思的是，杰利内克所开创的数据驱动方法论，或许能在欧陆哲学的语言理论中找到哲学上的同路人。

因此，我们对这一关于大语言模型的观点持异议，并试图论证：大语言模型或许恰恰是在进一步远离基于规则的体系，并且可能在欧陆哲学所提出的语言理论中找到支持与概念上的桥梁。它们映照出语言模型研究者所发展出的一些理论，最著名的是“分布假说”（Gastaldi, 2021），但在处理语言问题时，它们所借助的概念场域更为宽广，不受限于计算机所绑定的那种应用型推理形式。这意味着，我们试图在经典与现代的语言理论之间，以及与基于Transformer的语言模型之间，搭建一座概念桥梁。因此，我们不是要把基于Transformer的AI视为与人类使用语言的方式完全异质，而是认为两者之间存在着令人惊奇的契合。不过，这种契合建立在一系列本体论抉择之上，同时也对这些抉择产生影响，我们会在文中加以标示。我们的主张是：首先，欧陆哲学——尤其是海德格尔和拉康——所发展的语言理论，更适合用来理解大语言模型；其次，一个被称为“形式化的僵局”（Badiou, 2006, p. 5）的问题同样出现在大语言模型中，但由于这个问题本身并未被当作一个问题来认真对待，且它并非计算机科学固有的难题，因此它削弱了模型表征语言的方式。于是，我们的论证要点不是大语言模型以相同的方式复制了人类语言结构，而是它们接近语言的方式以及它们失败的方式——尤其是在否定性和形式化僵局方面——揭示出一些关键的本体论洞见。本文旨在提供一种新颖的视角，将计算机科学与欧陆精神分析哲学连接起来。因此，读者可能会在其中一个或两个领域感到陌生。

## 2. 词与大语言模型

要理解为什么拉康式的、或更广义地植根于欧陆哲学的进路有助于思考当前的人工智能模型，我们先来具体看看当前的AI：大语言模型。我不会深入技术细节，因为已有无数其他论文可以加深理解。不过，我们还是来简略地看一下，一个提示词是如何被最先进的语言模型的一般技术结构所处理的。这里我们使用Vaswani等人（2017）所详述的Transformer架构的简化版。

输入首先经过一个输入嵌入层，该层将序列转换为一组连续的向量表示（参见Mikolov等，2013）。大语言模型将输入序列拆分为 token ，并将其转换为向量表示，以捕获每个 token 在序列中的含义和上下文。这一过程由输入嵌入层完成。位置编码被添加到输入嵌入中，以引入序列顺序，使模型能够辨别 token 在输入中的相对位置。因此，第一步在Transformer处理语言的方式中引入了两个要素：第一，它用数学表示替换了单词，这种数学表示嵌入了该词在一般实践中与其他词之间的关系（通过统计分析获得）。第二，这些向量被准备好，以便由同一输入中的其他 token 表示来进行语境化。到了这一步，句子中的每个词实质上都被替换为一个潜在的与其他词发生关系的节点，模型将其捕获为多维向量。

在初始输入嵌入之后，自注意力层使得大语言模型能够通过将词与其他词连接起来，以不同的侧重点来读取这个句子（参见Vaswani等，2017，第3-6页）。 token 的向量表示经过模型中多层自注意力机制。在每一层，模型基于每个 token 与序列中所有其他 token 的关系来计算其注意力分数。注意力分数被用于加权向量表示，使模型能够更关注序列中每个位置的相关 token 。这里有一个关键要素进入计算：注意力分数被用来更新向量表示，使得比如“这个”一词可以指代某个特定的对象。节点式表示吸收了源自另一个向量的联想链接。以“时间是小偷”这个隐喻为例：它会被以一种方式解读，使得“时间”的表征包含“小偷”的联想力量。这一机制体现了输入中词与词之间不同层级的关联。这是一个重要步骤，因为它将句子或提示词的结构从线性处理的模式中解放出来，允许对词进行多样而复杂的解释。

这些加权后的向量表示随后被传入一个前馈层。每个前馈层由一个稠密层和一个激活函数组成，对向量表示进行非线性变换。在大语言模型（如GPT-3）中，前馈层是模型的重要组成部分，负责将输入序列转换为更具表现力的、高维的、基于向量的语言关系表征，从而捕捉词之间复杂的关系（参见Brown等，2020）。简而言之，大语言模型中的前馈层和注意力机制的工作原理是：取输入序列中每个词的向量表示，将其转换为新的、语境化的向量表示，以捕获特定提示词上下文中词之间的更高层次特征和关系。这里发生的是，原始提示词的广义表征与模型的语言表征相互交织并语境化。每一层对原始提示词做两件事：首先，通过乘以权重矩阵并加上偏置向量，对序列中每个词的输入向量表示进行线性变换。这一步至关重要，其操作由机器学习过程决定，该过程允许模型通过权重矩阵来附加这些权重（参见Rumelhart等，1986）。权重矩阵是在训练过程中学习到的参数矩阵，用于将每个词的输入向量表示转换为新的、更高维的向量表示。

前馈层的输出结果是一个新的、更高维的词向量表示，它捕获了更高层次的特征以及词之间的语境化关系。以“king”这个词为例，作一个简化的高维向量说明。“king”的向量表示是一个多维向量，其中每个维度捕获该词与语言中其他词之间的不同特征或关系。其中一些维度可能捕获句法关系，比如“king”“rules”和“kingdom”之间的主谓宾关系；另一些维度可能捕获语义关系，比如“king”与其他王室词汇（如“queen”“prince”“duke”）的关联；还有一些维度可能捕获语境关系，比如“king”常出现在历史文本或奇幻故事的语境中。模型使用“king”这一 token 的语境化向量表示，通过注意力头动态更新具体语境和联想链接，从而凸显其适应不同语言环境的灵活性。因此，在“马丁·路德·金”的语境中，该向量携带的联想信息不同于“法国国王”中的“king”。模型通过根据周围词汇调整“king”的表征向量来区分这些语境，从而捕获不同的含义。这一注意力和前馈层的过程会根据具体模型架构重复多次。模型在每一层更新 token 表示，自注意力机制使其能够根据上下文动态调整含义。

模型的最终输出通过输出层生成，该输出层预测序列中下一个词的概率分布。生成过程涉及迭代地每次预测一个 token ，将其附加到输入序列，并更新上下文以进行下一次预测。输出层是一个softmax函数，这是一种将实数向量转换为概率分布的数学函数（Bishop, 2006, p. 198）。softmax函数将原始分数转换为总和为1的概率，帮助模型决定最可能出现的下一个词。softmax函数常用于分类任务，其目标是预测输入属于多个可能类别中每一个的概率。然后模型从该分布中采样以生成序列中的下一个词。在我们的例子中，大语言模型会通过将初始序列传入输入嵌入、自注意力和前馈层，然后使用输出层预测下一个词，从而生成提示词的续文。生成的续文会被添加到提示词中，重复该过程直到达到所需序列长度。（关于GPT系列大语言模型的结构与基础的进一步阅读，参见Radford等，2019；Brown等，2020。）

所以，用更接近非技术读者的语言来重述这个例子：我们得到的大语言模型是一个高度复杂的语言模型，它通过海量文本的训练，学习哪些词通常（即统计上）彼此相关。它通过将每个词转化为数学表示，然后分析这些表示与其训练数据中提取出的关系之间的关联，并将它们与输入中的其他词进行语境化，从而表征这些关系。一个常见的反对意见是，这种构建语言模型的过程纯粹是统计性的，但这并不完全正确。统计分析的产物是带有内在权重和与其他 token 链接的 token 。虽然这些可能是基于统计推断生成的，但所创建的结构本身并非统计性的。相反，它可以被看作是一种习得的、高维的、基于向量的传统与实践性语言关系表征。这种表征虽然本质上是数学的，但它试图捕捉训练数据中存在的词、短语以及更广泛语言结构之间复杂的语义和句法关系。

这种基于注意力的方法突显了Transformer模型对输入措辞的敏感性，因为注意力机制基于上下文动态地链接 token ，甚至超越了训练期间建立的那些模式。因此，措辞或句法上的细微变化都可能导致模型产生显著不同的解释和输出，这既体现了它的灵活性，也显示了其潜在的不可预测性。所以，这些模型并非仅仅运作在一个复杂的联想关系网络之中，而是在推理过程中不断地移动和重构这些网络——尽管这些移动只是被实现出来，而不会被保存。这催生了“提示工程”的想法，作为应对这些局限或将其作为一种特性来利用的方式。然而，如果认为提示仅仅是一种缺陷，而不是注意力机制与存储数据交互的核心要素，那就错了；用通俗的话说，提示构成了生成输出的视角。

这种基于词的处理方式，当然使它远离了乔姆斯基所倡导的基于语法的路径。但这也意味着，欧陆的弗洛伊德/海德格尔传统——它强烈强调词作为指向其他能指的能指之复杂形式关系的重要性，而非侧重于句子——与大语言模型所趋近的语言理论要贴近得多。所有这些可能看起来是对大语言模型的过度技术性介绍，但与我们形成鲜明对比的是，我们认为大语言模型相当接近人类使用语言的方式。

## 3. 未分化的众数

要理解像GPT-4这样的大语言模型如何达到对语言的真正理解，参考马丁·海德格尔关于词之角色的观点会有所帮助。海德格尔的语言思想与大语言模型处理信息的方式，在某些有趣的方面相契合。具体来说，他对词、甚至更小的词片段的关注，与大语言模型处理 token 的方式——即可以是完整词也可以是词的一部分的片段——有着对应关系。这种比较有助于在哲学上搭建起一个桥梁，让我们理解意义是如何从更小的单元中建构出来的，以及大语言模型如何通过 token 化来建立语言理解——这对读者来说也更易接近。

海德格尔的语言概念强调，词并非孤立的实体，而是由携带意义的更小成分所构成的指涉节点，这与大语言模型从单个 token 出发构建语言理解的方式相似。例如，海德格尔讨论过他自己哲学中的术语是如何通过组合更简单的子词（如“Gestell”中的前缀“Ge”）来构造的。他暗示，即使在最小的层面上，比如字母或词片段，意义也是通过一个联想网络来塑造的——这一概念与大语言模型通过代表词和子词元素的 token 及其关联的相互连接层来创造意义的方式相呼应。正如大语言模型依赖海量数据集来形成这些关联一样，海德格尔的观点也强调，意义产生于各部分之间的关系，而非孤立的符号。海德格尔的语言观与大语言模型的机制都认为，意义源于一个相互连接的部件系统——理解是由更小的语言成分之间的联想建立起来的，而不是来自孤立的或完全成形的概念。

本节将考察海德格尔关于词的观点，及其与大语言模型理解和处理语言的方式的关联。把词视为联想节点，在海德格尔的著作中并不显而易见，但仔细考察会发现他清晰地阐述了这个概念。可以说，这是他作品中一个由来已久的进路；海德格尔将词描述为“Wortmannigfaltigkeit”的一部分，即一种词的多样性（Heidegger, 1979, p. 373）。这一概念暗示词本质上是节点性的、相互连接的。此外，在他的逻辑学著作中，海德格尔展示了“Urworte”（源初之词）——比如希腊语的“Φύσις”（Heidegger, 1984, p. 131）——如何从根本上塑造了我们对存在者的认知和实践关系。这些“源初之词”至关重要，却从未完全透明，这呼应了拉康的“主人能指”或布卢门伯格的“绝对隐喻”。海德格尔还将历史的先验框架，即存在的结构，视为核心依赖于诸如希腊语φύσις这类源初之词的模态和联想力量。因此，海德格尔的框架强调了词及其联想力量在塑造意义中的核心作用。

然而，除了这些语言的本体论锚点之外，还可以说子词也早已在他的语言概念中被讨论过。海德格尔认为，日常使用的每一个词都是由词与词之间的连接构成的：“一个词作为整体，并非从对事物本身的首要的、源初的经验中抽取出来，而是从先入之见和最切近的物之看法中得来。”（Heidegger, 2005, p. 12）我们也可以看到，即使是子词也已经被这样一种多样的链接所结构。以他对前缀“un-”的讨论为例，当他将“无蔽”作为“Aletheia”（真理）的恰当翻译时：

> “‘无蔽’中的前缀‘un-’可以意味着遮蔽被去除、取消、驱逐或禁止，而去除、取消和驱逐在本质上是不同的。”（Heidegger, 1998, p. 14）

即使在单个字母的情况下，海德格尔也指出：“‘作为某物的某物’[是]在背景中的！”（Heidegger, 2007, p. 113）——这意味着对海德格尔而言，意义作为关系纽带和指示向量的结构，已经存在于单个字母的层面（这使我们能够直接联系到拉康思想中作为‘链接纽带的词’的能指概念）。这与海德格尔本人对“并置式翻译”的坚持相吻合，正如Groth（2017, p. 143）所讨论的，这种翻译同样聚焦于词而非句子。因此，我们在海德格尔的语言概念中发现的，是对词的节点结构的一种概念化——这种结构从单个字母、子词元素和普通词出发，通过联想链接构成——这标志着与Transformer架构的多维向量的第一个强有力的平行。

再举一个海德格尔哲学中最重要的词为例：存在（being）。在《形而上学基本概念》中，海德格尔通过语言中的存在概念——即口语中的“是”（is）——来处理词的地位问题。这意味着，他不仅旨在概念化一个关于存在的本体论概念，而且首先为我们提供了关于词在他的语言理论中如何运作的细致理解。他描述性地指出，在一个句子中使用“是”可以表达多种含义，即“如此存在和本质存在、实存和真存在”在同一句子中。这种模糊性——海德格尔首先通过历史上对存在概念使用的比较来揭示——正如他所论证的，是“是”作为存在的一种积极现象。因此他说：

> “有必要将‘是’的这种独特的漠然性和普遍性，理解为系词的原初且首要的本质，或者从外部称为系词的东西。”

因此，对命题中存在的理解的出发点，是“是”的“完整的未分化的众数”这一意义视域。关于这一意义视域，海德格尔在《存在与时间》中就已经强调，词最初只是一个指涉的整体（Heidegger, 1967, p. 87），其本身并不指向存在，而只是使得对存在本身的指涉成为可能。因此，一个词的意义不在于对存在的指涉，而在于它与其他意义的关系，或者用拉康的话说，在于指涉其他能指。这与拉康的观点一致，即语言是一个能指网络，每个词的意义由其与其他词的差异和关系来定义，而非直接指涉对象或概念。这种意义，正如海德格尔在其早期著作中已经指出的，最初并不指向可感之物或对象，而是指向其“为何”或“为了-之”（Wozu或Um-zu）。这个“为何”原是实践性的，植根于“知道如何”，即它总是已经被框定在一个意义的关联性语境中，而这个语境总是已经超越了任何具体的给定之物。

就Transformer型大语言模型而言，我们看到，大语言模型创建其自然语言模型的过程，与这种关于语言由词片段构成的话语相呼应，因为它在同样程度上也将单个 token 表征视为来自一个可比较的、未分化的、数学化链接之众数的多维向量——这一众数植根于实践（即其训练数据中所呈现的书写实践），正如海德格尔假定这一众数植根于实践一样。注意力机制随后试图通过将提示词再次与训练数据生成的权重进行比较，来把握提示词的意图。这意味着，注意力机制在此充当一种隐喻性链接的形式，因为它可以将那些在前馈层中没有链接的模式链接在一起。在上面讨论的隐喻“时间是小偷”中，模型评估“时间”如何被“小偷”所浸润，说明了一种联想之间的动态交互，从而转变了对“时间”的理解。大语言模型会首先将序列中的每个词或 token 编码到一个多维的关系空间中。这些嵌入提炼了一个词在更广泛的语言网络中的语义和句法倾向。通过注意力机制，模型识别并强化词之间的重要连接，创建一个加权联想网络。这不是一个静态映射，而是一个持续的语境化重新解释过程，其中“时间”的向量表示被“小偷”的影响所修改，通过其与“盗窃”的纠缠，重新配置了“时间”作为一个概念的联想链接。

这种能力反映了拉康所说的“能指从其词汇连接中的撕裂”（Lacan, 1993, p. 218），以建立与另一个能指的新联想纽带（Lacan, 1993, p. 219）。在这里，“时间”整合了“小偷”的潜在联想，生成一种新颖的、语境化的意义，超越了表面的组合。如果没有这种联想和隐喻功能，语言将无法将意义构成为一个结构化的、相互交织的理解场域。大语言模型的注意力机制展示了这种交互，暂时将不同的模式联合起来，形成一个综合的联想网络。这些连接作为临时建构物，引导模型的语言生成——这强调了关系性和视角性在语言形成中的作用。通过利用其训练数据中的联想模式，模型执行了一种综合行为，类似于人类认知中隐喻的链接。这标记的不是语言创造力，而是语言作为动态意指系统的基本架构，其中隐喻和联想支撑着表达的连贯性和清晰性。拉康的公式 \(f(\frac{S}{S})S \cong S(+)s\)（Lacan, 2006, pp. 428-429）代表了这种替换机制，其中能指 \(S\) 被另一个能指 \(S'\) 所转化，通过联想位移产生隐喻意义。这表明隐喻不只是简单的替代；而是两个已经被识别为复杂网络中的节点的能指的融合。在这种语境下，隐喻不只是用一个类似的词替换另一个词，而是创造了联想通路的新模式。弗洛伊德已经将这种结构称为“凝缩”（Verdichtung），意指两组观念融合，允许一组的元素暗示另一组（Freud, 2010, p. 199）。这种形式描述，呼应了基于Transformer的语言模型在被提示时如何生成隐喻性联想——通过注意力机制影响语义表征，构建新颖的关系。

让我们简短地回顾一下海德格尔-拉康思想与大语言模型之间的这种联系带来了什么。海德格尔式的语言理解意味着，首先将词视为未分化的众数，即联想力量的节点结构，它们作为联想模式，构建了语言的述谓部分，也就是语言使用的显式语法和逻辑。我们在LLM中也发现了这种进路。

那么，如何更确切地把握这种未分化的众数，尤其是联系到海德格尔所预设的本体论视角？海德格尔本人说，语言，作为由意向性（即说话者）所结构的，接近那先于 \(\lambda \partial \gamma \infty\)（逻各斯）之本质的未分化众数。而对海德格尔而言，\(\lambda \partial \gamma \infty\) 总是比基于完整句子的述谓逻辑更多，尽管它也包含这样一种逻辑，但它是基于一个前述谓的立足点（Heidegger, 1976b, pp. 153-555），在其中述谓陈述已经由一种“作为”（某物作为某物）的结构所构成。因此，与乔姆斯基的语法不同，海德格尔将实践关系的多样性视为结构化逻辑系统的基础。其理由在于海德格尔从根本上思考“规定”概念的方式。海德格尔的核心假设是，任何融贯的逻辑都与否定性相关。因此，意义不仅是意向性指涉，而且这种意向性指涉与某种本身无法被指涉的东西相关，并且只有在指涉结构的失败中才能被积极地把握。在《存在与时间》中，这种指涉结构的失败是我自己的死亡（而非他人的）。不过，海德格尔后来在“争辩”中发展出关于意义之形式结构僵局的更精细概念（关于争辩问题的进一步阅读，参见Heimann, 2021）。但这还有一个更基础的方面，因为海德格尔在《什么是形而上学？》中假定，每一项规定都依赖于排斥。我们需要进一步考量这种排斥。

然而，要完全接近这一问题，我们需要借助拉康对这一结构的关注——将其作为精神分析的核心要素——从而充分理解语言的这种限制性和语境化要素的理论。拉康的语言分析建立在弗洛伊德对音素和双关语的分析之上，后者允许在词和子词之间建构和转移额外的联想链接——这些链接并非由内容连接，而是由作为实践的言语所连接。也就是说，他聚焦于这种“能指从其词汇连接中的撕裂”（Lacan, 1993, p. 218），将其视为语言的一个核心面向。正是在这一点上，作为表征联想力量之转移的隐喻进入了问题，但却是处于一个非常基础的层面。以《哈姆雷特》的开场白为例，他使用双关语表达了一个悖论式的观念：尽管克劳狄斯既是他的叔父又是他的继父，但他并非真正的亲属或同类：“比亲人多一点，比亲善少一点”（1.2.65）。在这里，意义的原初多样性被用来制造双关语，但我们也看到一种基于实践的言语中的转移。这种被说出的意指既包含这两个要素：它既与惯常的指涉保持联系，又以一种新的方式被语境化。这里需要注意的是，对拉康而言，这些音素和字母都是“部分对象”（Lacan, 2006, p. 693）——这意味着存在一种我们需要更仔细考察的限制本体论。部分对象并非如其名称所示的那样，是由其在一个整体中的包含来结构的对象；它们只暗示了一个包含它们的整体，而实际上并不被那种整体性所结构。

为了更深入地进入欧陆话语使我们能够标记的那些问题，让我们来看一下基于符号和否定的理论所遵循的本体论视角，以及为何如此。对海德格尔、弗洛伊德以及建立在这些思想家基本洞见之上的欧陆传统而言，乔姆斯基基于语法的方法本质上是对语言问题的一种形而上学解答，因为海德格尔认为对逻辑和语言的通常理解落后于实际的语言使用，并且建立在一种在场之庸常本体论之上（Heidegger, 1967, p. 10）。那么，对于遵循海德格尔的逻辑进路而言，要形成一种严格的哲学，唯一的方式就是接受深渊（Ab-Grund）作为理性（ratio）的核心。

## 4. 深渊与美学

与海德格尔相对照，乔姆斯基在其重要著作《句法结构》（2002）中阐述的语言理解表明，他的好理论与研究的观念，是由一种本质上是美学的观念所结构的，即“整个系统的简单性”（Chomsky, 2002, p. 56）。这种整体简单性的原则，相应地应当组织起寻找“一种元语言，用以描述编写语法的语言——一种元语言，用以描述任何为其构建了语法的语言”（Chomsky, 2002, p. 54）。显然，这里的简单性观念充当了一种对抗力量，以抵御促使人们思考元语言的无限倒退之威胁。但这也表明，在乔姆斯基思想中突出的规定之隐含观念，是一个由内部绝对原则所支配的封闭系统。这种由一个小的内部规则集组织起来的连贯系统的观念并不令人惊讶，而且在限度内，它是最可行的进路，尤其是对于机器而言。相应地，乔姆斯基将语言理论的目标呈现为一台机器，它必须提供“一种实际且机械的方法，来实际构建语法”（Chomsky, 2002, pp. 50-51）。这台机器，正如我们从乔姆斯基等人的评论中可以得知的，是“先天的、由遗传安装的‘操作系统’，它赋予人类生成复杂句子和长串思想的能力”（Chomsky et al., 2023）。现在，对于普通机器——比如任何一台你能拿到的电脑——这种系统观念运作得非常好，尽管也有一些限制；不过，事实证明在某些情况下有必要思考让计算机绕过那些不符合这种理想的数据和输入的方法——比如次协调逻辑和模糊逻辑。乔姆斯基对简单性的偏好，反映了一种更广泛的本体论假设，即关于系统的融贯性和封闭性——而像海德格尔和拉康这样的欧陆思想家则认为这种立场不足以理解语言中固有的不确定性和否定性。

一种根本不同的视角来自这样一个假设：既然机器可以按某种方式设计，那么口语（以及更广泛地说，实在）也必然符合那种设计。尽管它可能因其被认为是严格的而获得一些可信度，但它最终代表了神学对科学领域的一种隐蔽渗透——通过假定古典系统概念的某种公理优先性。值得一提的是，格雷厄姆·普里斯特在其2006年《矛盾》一书的序言中，有效地展示了关于一致性和系统之必要性的观念，在多大程度上仍然渗透在分析逻辑话语中（Priest, 2006, p. XVIII）。相比之下，欧陆的逻辑话语正是以解构这种神学-本体论为前提的。诸如马丁·海德格尔、雅克·拉康、阿兰·巴迪欧，以及更近的甘丹·梅亚苏（2008）等著名思想家，都批判了这样一种观念，即实在可以被一个系统的、融贯的、且在理想情况下美学上简单的理论所表征。

这从根本上改变了语言被理解的方式，尤其是在系统性的语境中。为了厘清当前的问题，有必要指出欧陆语言话语与乔姆斯基思想所源出的那个话语之间的根本差异。与伯特兰·罗素（1905）在其摹状词理论中所阐述的哲学——其中，作为主要出现时指称空无的命名在本质上是假的——截然相反，我们在海德格尔、拉康以及欧陆话语中所发现的进路，是对这一观念的倒置，正如雅克-阿兰·米勒（2002）所指出的。对拉康、海德格尔以及欧陆话语的其他核心代表人物而言，只有那些指向激进不确定的命名才能被视为真理的构成要素。虽然这对不熟悉该话语的人来说可能显得奇怪，但它并不像看起来那样远离经典的分析认识论。卡尔·波普尔（1935）以其“证伪”概念接近了类似的想法——将证伪视为理论系统之外唯一真正接触实在的途径。然而，欧陆话语在相当大程度上关注的，是形式论证与“形式化的僵局”（Badiou, 2006, p. 5）之间的相互缠绕问题。汉斯·布卢门伯格（2010）很早就表明，这个问题在古典哲学中根深蒂固——其中系统本质上是围绕一个“绝对隐喻”来定向的，即一个空洞的指称，它支撑着理论而非损害它。

那么，我们如何在这种连接上建构意义？一种解决方案是某种关于这种连接的实用主义，同时结合一种避免进一步问题的逻辑理解：如果你假设逻辑与经验实在本质上是分离的，那么我们就不需要思考它，因为它没有意义——而这种实用主义的间隙，通常就是旧日的哲学之神在新名称下悄悄溜回来的地方。早期维特根斯坦的神秘主义，虽然表面上在朝着欧陆思想家的方向移动，但本质上把这个难题留给了神学家。然而，如果这种强烈的限制本身不过是些隐喻，它们被构造得看起来严谨而严格，而实际上理论变得相当奇怪——那我们就在接近另一个问题了。斯拉沃伊·齐泽克将其表述为我们的形式思维能力，它可以延伸到实在的无根基性（虚空），超越了有神论版本的基底实在所预设的东西（Zizek, 2012, p. 726）。类似地，甘丹·梅亚苏（2008）将这种虚空或混沌——它无非构成了一个根本不变之实在的缺席——标记为数学推理的绝对基础。

这种本体论上的谓词倒置，导致了对语言基本要素的不同理解。因此，重点从关于事物是什么的陈述（谓述），转移到了那些未被说出的、或那些打乱了语言中预期模式的东西的意义上——从而突出了缺席和否定在意义生成中的重要性。谓述不再是意义性语言的核心要素；相反，正如海德格尔所指出的，一个前-述谓的否定性语言要素走到了前台：句子融贯结构中的一个断裂或间隙。要处理这一间隙，需要一种更复杂的否定进路。因为句子或系统的那一要素——它通过指示一个不确定的剩余而将其与虚空相连——仍然维系着句子或系统的系统结构。这里进入的是各种形式的否定，它们从经典的“缺失”扩展而来，并在精神分析中被形式化为“挫败”和“阉割”，与经典的“缺失”并列（Lacan 2020: 29）。我将简要区分这三种关系：

**缺失（Privation）** 是经典形式的否定，首先由亚里士多德标记出来。缺失是对某种实在之物的缺乏，然后被一个象征对象（a）所标记。这意味着，作为一种否定形式的缺失，已经需要一个形式化的秩序系统，因为纯粹描述性或感官性的视角无法通达“缺乏”这一概念——我们需要一个象征结构来解释那个缺失的对象，使其显现出来。例如：丢失的自行车之所以是“丢失的”，只是因为它本应在它的位置上。它被一个可被指称的否定性对象所替代，而感性的或想象的方式如果没有象征支撑，就无法看到这种缺乏。作为否定的缺失总是指示着对某物的否定，因此“用于表达一个否定性的存在命题”（Carnap, 2004: 96）。在这个意义上，逻辑否定使我们能够设立一个象征性对象（a），从而使我们能够“看见”一种缺乏。因此，否定不仅仅是不在场，它是一种建构性操作，创造了对缺失之物的表征，使我们能够概念化和交流关于缺席或矛盾的信息。这标记了一个比纯粹缺席更复杂的问题。计算机能够处理这一点，因为它们能够标记确定的缺席，而这种对缺乏的“实证化”在语言模型中是核心的，因为否定只是正面 token 之间的链接（Gubelmann & Handschuh, 2022），尽管大语言模型在初期对此确实有些困难（Ettinger, 2020; Kassner & Schutze, 2020）。然而，由于想象域深深参与我们的思维过程，它也创造了一种独特的经验性否定——这种否定只有在我们假定想象域是我们思考的通常出发点时才会浮现。于是，想象域就是将系统性包含为对经典“假”（falsum）的一种重新表述。这一论点首先由海德格尔明确提出，他在评论尼采时指出，与其说是表象与被表象者之间的不协和（这会依赖于所指与能指之间的强关联作为真理的基础），不如说引入了一种新的假类型——即表象的完全且永恒的一致性，而与被讨论的对象无关（Heidegger, 1996, p. 347）。

与这种作为思想出发点的“假”的特定关系，正是拉康所谓的“挫败”（frustration）——即一种表象关系的失败：某物以某种方式被想象为适合其所表象的对象，但实在对象并不符合这些从这些对象的部分性中涌现出的想象性假设。拉康明确指出，作为一种缺乏，挫败产生于他所谓的“想象域”——即可感物的结构性显现（Lacan 2020: 30）。这一点至关重要，因为想象域中与对象的关系，其结构特点是缺乏否定性，因此它假定其对象具有一种整体性或格式塔——用拉康的公式来说，即“以部分代整体”（Lacan 2026: 55）。在这个意义上，我们相关的大多数对象都是“部分对象”，它们通过想象域而“变为整体”（Dolar 1991: 10），因为作为实在对象，它们永远达不到想象域关系中所隐含的那种无缺乏的一致性。因此，挫败作为一种否定性，是被假定的表象与被表象的实在对象之间的不协和或间隙。然而，这种否定性并非“缺失”，因为表象并不包含一个被否定的、关于被表象之物的特定要素，而是标记了一个不确定的未知之存在，即表象与被表象物之间的不协和。被挫败的是世界的“模型”——这可以通过一个缺失而发生，但并不等同于缺失。因此，被标记的否定性不是某种确定的、被否定的东西，而是某种未知的或出乎意料的东西。正如波普尔在其证伪理论（Popper, 1935）中指出的，一种理论的挫败，尽管是一种认识论上的失败，却与科学的实在对象相关——该对象通过抵抗我们的假设而显现自身。在认识论上，这种否定与实在有着强关联，因为虽然我们无法完全证明任何经验理论，但我们却可以通过挫败一致地反驳它。这种作为认识过程的关系，在机器学习中正变得越来越重要，我们在不同科学中以各种方式看到它被使用。然而，根据拉康，它的起源并不仅仅是一种期望，而是其中隐含了一种整体性或系统结构。因为它与阉割有着内在联系：“阉割的层面恰恰是确立了挫败之必然性（在其真正秩序中）的东西”（Lacan 2020: 92）。这把我们引向了阉割所标记的真正本体论问题。

**阉割（Castration）** ，正如弗洛伊德和拉康所确认的，标记了由任何规定性所引入的纯粹形式上的否定性（作为“内在地与象征秩序相链接”的东西，Lacan 2020: 53）。本质上，定义某物本身就创造了一个边界，包含了某些要素而排除了其他要素，从而在被定义的领域之外引入了一个不可避免的不确定性要素。每一种形式的（象征性的）规定或命题都会产生这样一个确定的内侧和一个不确定的外侧——正如海德格尔在《什么是形而上学？》中所详述的。这可以通过在黑板上标记某物来说明。由粉笔轮廓所确定的标记空间决定了内侧，而不确定的外侧则是规定本身的一个必要要素——它本身必然是未定的。尽管我们现在可以在黑板上创建一个更大的确定场域来包含第一个规定，但我们将再次依赖于一个不确定的外侧。然而，这种激进的、不确定的否定性，只有在我们放弃斯宾诺莎意义上的绝对者时才浮现。古典地，阉割的形式问题可以被忽略（比如在牛顿物理学和19世纪科学中），通过引入一个或多或少明确的神学绝对概念——一个最终的、无限且完全自我决定的统一体，名为“上帝”。这将必然的不确定者还原为一种认识论上的不确定者——即我们只是尚不知道的东西——而不是任何形式结构的必要要素。尽管神学论证现在已被削弱，但它的一个变体仍然存在，即想象域与象征域融合成一个“被想象化的象征”，后者运作时没有这种剩余——同样的效果可以达到。这一点已被海德格尔（Heidegger, 1999: 82-96）以及后来的巴迪欧（Badiou, 2006）突出地讨论过，我们也已经在关于AI概念化的研究中标记过这一问题（Heimann & Hubener, 2023）。

这里重要的是，挫败和阉割的结构性要素共同构成了通往间隙的通道——例如，作为布卢门伯格意义上的绝对隐喻，它结构了一个系统的融贯性。当然，对这种隐喻的更仔细分析总是会揭示系统的实际不一致性，并将其标记为一个不代表任何东西的象征对象——一种标记这一间隙的缺失形式。这在当前的大语言模型中是缺失的，因为否定目前由正面权重来代表（Morante & Blanco, 2021）。不过，也可能我们这里谈论的是机器智能的本体论界限——因为对虚空的形式指示可能无法在物理上被再现，这标记了一种物理限制，而它表面上似乎只是数学的问题，实际上却是一个“技术人工物”（Turner, 2014）。因此，拉康的逻辑进路所包含的，正如阿兰·巴迪欧（2006, p. 5）所指出的，是“明确的拉康学说”——即“实在是形式化的僵局”。这种由僵局本身所支撑的、形式主义中的经验断裂，正是拉康传统在“阉割”这一标题下所思考的东西，而它与一致性、系统和法的关系，已经得到了广泛的审视（参见例如Copjec, 1994; Ragland-Sullivan, 2015; Zupancic, 2017）。

## 5. 视角即一切，也即虚无

如上所述，注意力机制为大语言模型的语言使用和理解提供了一个关键要素，并且它可能使我们——即便在系统内部——标记出视角作为知识形式要素的重要性。由于语言模型的语言表征是由词或 token 之间的加权关系所创建的，对这些关系的一种无语境化的表征只会导致荒谬的词堆。Transformer模型的非凡能力恰恰在于其注意力机制，它允许模型处理每个 token 所代表的节点网络，并使用源自其他 token 的具体语境，同时忽略与提示词无关的关系。大语言模型使用一种纯粹形式的、象征性的视角（这里没有视觉元素，只有根据注意力机制的复杂结构所构造的探究方向），我们可以注意到，如果我们接近其形式结构，它缺乏视角的一个核心要素——即与无限判断或阉割的联系，而这也是视角所包含的。在这种情况中，什么是阉割？如上所述，拉康意义上的阉割标记了一个被不确定性的外侧所限定的确定空间。我们可以以各种形式与这一点相关联——可以是通过一个（非修辞性的）问题，标记了现实中尚待探索的部分，也可以是通过思考给定系统的一致性——然而，对这一问题的任何标记本质上都是象征性的，并非主要基于经验。

然而，基于Transformer的模型依赖于 token 之间的正面链接，这些链接通过接近否定性的高概率来结构。用拉康的话说，它遭受着一种激进的“除权”（foreclosure）形式——即严格地无法与其视角中被排除或被否定的要素建立关联。拉康早在今天的思维机器真正出现之前就指出了这个问题：

> “对于一台机器来说，任何没有准时到来的东西，就简单地被搁置一边，不会对任何东西提出要求。但对于人来说，情况并非如此……”（Lacan, 1991, p. 89）

拉康在这里指出，机器缺乏与人类相同的那种“不在场”的紧迫性——人类会由于错过或失去的东西而受到困扰、被其影响。这种“有所要求”的缺席，正是大语言模型难以把握的东西。它们可以处理形式上的否定（比如“不”这个词），但这种处理仍然是在正面关联的层面上进行的，而非真正与一个结构性的间隙相关联。大语言模型对否定的处理，即使在表现良好时，也仍是一种“实证化”的缺失，而不是对虚空本身的某种开放性。这导致了模型在面对需要真正理解否定性——即那些不仅仅被正面表征所标记的否定性——的语境时，会出现特有的失败模式。例如，它们可能在反事实推理、真正的矛盾处理或深层语义反转方面表现不佳。

但这里还有一个更深层的本体论要点。如果我们把注意力机制理解为一个纯粹形式化的透视装置，那么它缺少的正是那个使视角得以可能却又不被视角本身所包含的盲点——即拉康所说的“凝视”（gaze）。凝视不是我们从某个位置看到的东西，而是那个使我们能够去看、却在我们视野中留下一个污点（stain）的结构性缺口。大语言模型具有一种“视角”（通过注意力权重分布），但它没有对这个视角本身的反思性关系。它无法将自己与那个构成其自身视角的“外部”联系起来。因此，它的“视角”只是一种权重分配，而不是对自身有限性的经验。这意味着，虽然大语言模型在某些层面上惊人地接近人类语言使用（如我们前面论证的），但在否定性和自我指涉的极限处，它们暴露出一种根本的差异。

我们并不是说大语言模型需要被“赋予”某种类似人类缺位体验的东西才能变得真正智能。我们的论点更为审慎：通过将大语言模型与海德格尔-拉康式的语言理论并置，我们可以看到，这些模型在形式结构上确实与欧陆语言观有着深刻的亲和性——尤其是在词作为节点、意义作为关联网络、以及上下文敏感的动态重组方面。然而，这种亲和性同时也突显了一个关键性的遗漏：即对否定性本身（而非仅仅是其正面痕迹）的无法通达，以及对形式化僵局的遮蔽。欧陆哲学传统告诉我们，任何形式系统都有其外部，那个外部不仅是偶然的未知，而是结构性的必然——阉割。大语言模型的架构并未纳入这种结构性外部，因此，尽管它们可以生成令人惊叹的类人文本，它们仍然缺乏那种“围绕虚空绕行”的能力，而后者正是人类语言实践的标志性特征。

最终，这意味着我们既不应像乔姆斯基那样简单地贬低大语言模型，也不应夸大其能力以至于认为它们已接近人类智能。相反，我们应该将它们视为一面镜子，映照出我们自己的语言结构——那些我们建立关联、形成隐喻、构建意义的能力——但同时也映照出我们与否定性、与不可言说者、与自身盲点的根本关系，而这恰恰是机器所无法复制的。在这个意义上，大语言模型不仅是一种技术工具，它们也成为了一个哲学实验——它们让我们以一种新的方式看到，人类语言并不只是一个可以被完整形式化的系统，而是一个始终在绕行其自身虚空的结构。
