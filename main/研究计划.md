## 研究计划
### 一、研究题目

大语言模型的语言现象与海德格尔语言哲学：从”源始话语/通常语言”的区分看 LLM 与闲言的界限


### 二、研究背景与动机

海德格尔在《存在与时间》第34节的结尾发问：”语言是世内上手的用具吗？抑或它具有此在的存在方式？抑或二者都不是？”在《存在与时间》中海德格尔明显搁置了这个问题，而在其后期文本《关于人道主义的书信》中，海德格尔提出语言是存在之家的命题，将语言与存在的关系推至哲学思考的核心。

如今大语言模型（LLM）通过海量历史文本的训练，不具备任何此在式的生存却能够生成高度自然的语言，这构成了对海德格尔语言存在论的一个当代挑战。

当前学界对海德格尔与人工智能的讨论，多集中于其后期技术批判理论，将LLM视作”集置”的新形态，或是以梅洛-庞蒂的具身认知批判符号AI的离身性。这些研究都预设了海德格尔哲学作为批判工具的外在立场。

本研究不满足于简单地用海德格尔否定 LLM。依据《存在与时间》中关于领会、解释、陈述与命题的发生学考察，通常意义上的语言在陈述阶段才出现，而领会与解释阶段存在的是源始意义上的话语。LLM 生成的语言是通常意义上的语言，不是源始话语。本研究以此区分为出发点，将 LLM 的语言现象定位于通常语言层，并进一步比较其与闲言的关系，追问 LLM 的语言是否被闲言完全消化，抑或在某些环节溢出闲言的规定。

需要说明的是，”无此在的语言能否揭示存在”这一颠覆性命题并非本研究的论证目标，而是作为一项悬置的开放问题留在研究边界之外，指向后续研究。


### 三、研究问题

#### 核心问题

在海德格尔”源始话语/通常语言”的区分下，LLM 的语言现象应如何定位？它与闲言的关系是什么——LLM 的语言是否被闲言完全消化，抑或在某些环节溢出闲言，呈现为一种不能被闲言充分解释的语言现象？


#### 子问题

1. 在《存在与时间》的发生学考察中，源始话语与通常意义上的语言如何区分？领会、解释、陈述与命题各处在什么位置，闲言在这一结构中如何产生？

2. 从现象学角度描述 LLM 的语言现象，其在严格意义上更接近源始话语、通常语言还是闲言？

3. 以海德格尔对闲言的具体规定（平均化、封闭、无根的流传）逐项对照 LLM 的生成机制，LLM 在多大程度上坐实了闲言？

4. 在对照中，LLM 的语言是否存在无法被闲言规定完全解释的溢出环节？这一溢出指向何种可能，是否触及”无此在的语言能否揭示存在”这一悬置命题的边界？



### 四、主要研究方法
1. 进行文本诠释与概念分析，解读海德格尔《存在与时间》、《关于人道主义的书信》、《在通向语言的途中》等一手文本，对领会、解释、陈述、语言、闲言、话语、道说等核心术语进行严格的定义与概念史辨析，梳理语言的发生学结构。

2. 以现象学的描述方法表述LLM。对LLM的语言行为进行现象学还原，悬置其技术架构，直接描述其呈现的语言现象的本质特征。

3. 对照经典技术哲学的人工智能研究，以德雷福斯对人工智能的现象学批判为对话对象，检验其具身性论证在LLM语言现象上的有效性。

4. 概念对照分析：以海德格尔对闲言的规定（平均化、封闭、无根流传、此在丧失发言权）为分析工具，逐项对照 LLM 的生成与输出机制，辨明 LLM 语言在何处坐实闲言、何处溢出闲言。

## 导师意见
 
需要注意的是，除了话语和空谈（闲言）外，海德格尔在《存在与时间》中关于理解（领会）、阐释（解释）、陈述和命题的发生学考察也特别值得关注。通常意义上的语言是在陈述阶段才出现的，在理解（领会）和阐释（解释）阶段有源始意义上的话语，但未必有通常意义上的语言。“语言大模型”中的语言是通常意义上的语言，不是源始话语。源始话语与海德格尔后期所说的语言大致是一回事。
