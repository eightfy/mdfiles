# Narrative Psychology

## 定义
叙事心理学（Narrative Psychology）是心理学的一个分支，研究人类如何通过叙事（故事）来组织经验、理解世界和做出决策。在 LLM 语境下，指利用叙事结构来引导模型的推理过程。

## 核心要点
1. 人类决策常以叙事形式编码和沟通
2. 叙事的基本元素（人物、场景、因果链、结果）与道德推理所需步骤高度对应
3. LLM 预训练语料中的叙事文本提供了实施这种引导的基础
