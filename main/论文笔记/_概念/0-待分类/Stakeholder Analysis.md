# Stakeholder Analysis

## 定义
利益相关者分析（Stakeholder Analysis）是识别、评估决策中涉及的所有相关方及其利益的过程，起源于商业管理和伦理学领域。

## 核心要点
1. 标准 CoT 在道德推理中常出现 stakeholder collapse（只提及 ≤1 个利益相关者）
2. NoT 强制要求枚举所有利益相关者的利害关系
3. Stakeholder count 是 NoT 的核心评估指标之一
4. 利益相关者数量从标准 CoT 的 1-2 提升到 NoT 的 4-7
