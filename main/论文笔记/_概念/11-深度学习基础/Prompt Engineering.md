# Prompt Engineering

## 定义
Prompt Engineering 是设计和优化输入提示以引导 LLM 产生期望输出的技术实践。

## 核心要点
1. 包括 system prompt、few-shot、CoT 等多种技术
2. 无需修改模型权重即可改变行为
3. NoT 是 prompt engineering 在伦理推理领域的系统性应用

## 代表工作
- [[NoT]]: 通过5段叙事结构的 system prompt 实现伦理推理质量的大幅提升
