# Dictionary Learning

## 定义
字典学习（Dictionary Learning）是一种寻找过完备基（"原子"）的方法，使得数据可以用这些原子的稀疏线性组合来重构。与 PCA 类似但使用过完备而非正交基。

## 核心要点
1. 可用于模型内部数据表示的稀疏自编码器（Sparse Autoencoder）
2. 对 LLM 尤其有效：句子可自然分解为大型字典中的概念组合
3. 稀疏编码是语言的良好归纳偏置
